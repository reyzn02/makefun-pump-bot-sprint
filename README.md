A Solana trading bot for pump.fun bonding curves: it buys young coins on confirmed momentum with buy pressure, then scalps them with take-profit, stop-loss, trailing and age-out exits. Deterministic, no network, no secrets.

## Run it

```sh
node main.ts
```
